# 🌌 Space Kids Arabic Studio (استوديو سبيس كيدز العربية)

أداة محلية متكاملة ومصممة خصيصاً لإنشاء حزم محتوى فيديو يوتيوب للأطفال باللغة العربية، تشمل: السيناريو، أوصاف الشخصيات، توليد الصور، والتعليق الصوتي، مع تصدير منظم جاهز للمونتاج.

---

## ✨ الميزات الرئيسية
- 📝 **توليد السيناريو:** إنشاء قصص أصلية وآمنة للأطفال عبر مصادر متعددة (Ollama محلي، Pollinations، أو نماذج متوافقة مع OpenAI).
- 👥 **اتساق الشخصيات (Character Bible):** الحفاظ على ملامح الشخصيات، الملابس، والألوان ثابتة في جميع مشاهد القصة.
- 🎨 **توليد الصور:** إنشاء أوصاف صور احترافية لكل مشهد وتنزيلها بدقة عالية.
- 🎙️ **التعليق الصوتي:** إنتاج ملفات صوتية باللغة العربية عبر مكتبة `edge-tts`.
- 📦 **التصدير:** حفظ كل مشهد في مجلد مستقل يحتوي على النص والصورة والصوت مع ضغطها في ملف `ZIP`.
